# Web Projects

A collection of websites showcasing the kind of frontend experiences I can build for clients.

These projects were created to explore different layouts, visual styles, and user experiences using HTML, CSS, and JavaScript.

## Projects

### Computer Store

A website concept for a computer store, focused on presenting products and creating a simple browsing experience for potential customers.

**File:** `Computadoras.html`

---

### Perfume Store

A website concept for a perfume store, focused on product presentation, visual design, and creating an attractive shopping experience.

**File:** `Perfumes.html`

---

### Magazine

A magazine-style website focused on content presentation, layout organization, and creating a visually engaging reading experience.

**File:** `Revista.html`

## Technologies

* **HTML5** — Page structure and semantic markup.
* **CSS3** — Styling, layouts, and visual presentation.
* **JavaScript** — Interactive elements and client-side functionality.

## Project Purpose

These projects serve as examples of different types of websites that can be developed for personal projects, businesses, and freelance work.

The designs and implementations focus on creating functional interfaces while adapting the structure and visual style to the purpose of each website.
